# Image credits

**The canonical, maintained credits file is [`public/images/CREDITS.md`](../public/images/CREDITS.md).**

It lives next to the images themselves and is updated in the same commit whenever
a photo is added or replaced. It records every site image with its subject,
photographer, source URL and license (Unsplash / Pexels / Bundesarchiv CC BY-SA /
owner-original).

This file used to hold a partial copy of that table and fell out of date. To
avoid two sources of truth drifting apart, it now just points to the real one.
Do not re-add a table here — edit `public/images/CREDITS.md` instead.
