# Social Graphics — posting guide

Five ready-to-post infographics are in `assets/social/` (1080×1350, the ideal
Instagram/Pinterest portrait size). Regenerate anytime with
`node scripts/gen-social.cjs`.

**Honest expectation:** these are professional, shareable assets — but nobody can
*make* something go viral. What works is posting consistently and being genuinely
useful. Treat this as a steady drip, not a lottery ticket.

Every graphic ends with `germanyguide.net`, so each post is a small traffic funnel.

## Where to post (by impact for *this* audience)

- **Instagram** — post as single images or a **carousel** (combine 2–3 into one
  swipeable post). Put `germanyguide.net` in your **bio link** (Instagram doesn't
  allow links in captions). Use Stories too, with the link sticker.
- **Pinterest** — *underrated and perfect for this.* Pinterest is a search engine;
  tall infographics like these get found for months/years and drive steady traffic.
  Create a "Living in Germany" board, pin all 5, put germanyguide.net as the
  destination link on each pin. **Do this — it's the best long-term traffic source
  of the bunch.**
- **YouTube** — if you make short videos (even simple screen-walkthroughs of the
  site), use these as thumbnails/end-cards and put germanyguide.net in the
  description. Or post them as **Shorts** with a voiceover reading the steps.
- **Reddit / Facebook groups** — drop the relevant graphic into a genuinely
  helpful answer (see `PROMOTION.md` for the rules — don't spam).
- **LinkedIn** — if you have a profile, "I built a free guide for internationals
  in Germany" + graphic performs well there.

## A sustainable rhythm

- **1–2 posts per week**, rotating the 5 graphics + reposting the best performers.
- Pin all 5 to Pinterest **once** — that keeps working with no further effort.
- When you write new guides/problems (Round 9+), we can generate matching graphics.

## Reusing / editing

The design lives in `scripts/gen-social.cjs` — edit the `GRAPHICS` array (titles,
items, accent colour) and rerun to make more. Ask me and I'll add graphics for any
new topic.
